## 玩法

- **自由输入**：没有固定选项，你想做什么就用文字告诉 AI 地下城主——「去码头找活干」「偷听商人的谈话」「拔剑冲上去」，由它裁定成败与代价
- **四条人生路**：从军（绿叉河、奔流城守桥）、经商（陆路到海路布拉佛斯）、魔法（红袍僧火之试炼）、守夜人（塞外巡逻、长夜之战）
- **六种结局**：白甲加身 / 金袍富商 / 光明之子 / 黎明的守望者 / 平凡史诗 / 陨落
- **数值系统**：生命、金币、声望、战斗、学识、魅力，客户端严格钳制 AI 的状态增量，防止数值失控
- **场景插画**：8 幅定制油画风场景图，随剧情自动匹配

## 技术要点

- 纯前端单文件实现（无构建步骤），通过 WorkBuddy 云服务免密钥调用大模型
- AI 以 DM 身份输出「叙事 + 结构化状态增量」，客户端负责解析、钳制与结局兜底
- 访客统计基于 IP 的 SHA-256 哈希（不存明文 IP），云数据库原子去重
- 进度自动保存在浏览器 localStorage
